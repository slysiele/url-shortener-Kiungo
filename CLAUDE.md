# CLAUDE.md: project guide for Claude Code

Kiungo is a SaaS URL shortener (like Short.io or Bitly) for East African businesses: Spring Boot backend, Angular frontend.
Read `docs/ARCHITECTURE.md` for the design and `docs/PLAN.md` for the roadmap before larger changes.

## Commands
- Backend: `cd backend && ./mvnw spring-boot:run` (Windows: `mvnw.cmd`). Tests: `./mvnw test`
- Frontend: `cd frontend && npm start` (dev server on :4200, proxies `/api` to :8080). Build/type-check: `npx ng build`
- Dev profile uses H2 at `backend/data/` and seeds `demo@kiungo.dev` / `demo1234`. Delete `backend/data/` to reset.

## Conventions
- **Backend**: package by feature (`link`, `analytics`, …). DTOs are Java `record`s in `*Dtos.java`. Throw `ApiException`
  (helpers: `notFound`, `badRequest`, `planLimit`) and never return error bodies by hand. Controllers get the user via
  `AuthUser.current()`. All endpoints live under `/api/v1/**` and accept a JWT or an API key.
- **Plan limits** live only in `user/Plan.java` and are enforced in services. A limit hit returns 402 `PLAN_LIMIT`, which the frontend turns into an upgrade toast.
- **Database**: never edit an existing Flyway migration. Add `V{n}__description.sql` that works on both Postgres and H2
  (use `BIGINT GENERATED BY DEFAULT AS IDENTITY` and `TIMESTAMP WITH TIME ZONE`). `ddl-auto` is `validate`, so entities must match.
- **Frontend**: standalone components with inline templates, signals, `ChangeDetectionStrategy.OnPush`, and the new control
  flow (`@if`, `@for`). HTTP goes through `core/api.service.ts`; models live in `core/models.ts` and mirror backend DTOs.
  Style with the CSS variables in `src/styles.scss` (`--accent`, `--surface`, …), never hard-coded colours, so all 4 themes keep working.
- **Copy**: plain, sentence case, say what happens ("Create link", not "Submit").
- **Docs**: when behaviour changes, update the matching file in `docs/` and add a line to `docs/CHANGELOG.md`.
- **Tests**: extend `FullFlowIntegrationTest` (MockMvc) for new endpoints.
